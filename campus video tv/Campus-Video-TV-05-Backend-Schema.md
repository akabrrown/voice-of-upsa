**BACKEND SCHEMA**  
**Campus Video & Voice of UPSA TV**  
Database design — Phase 1 tables, relationships, and RLS  
**Prepared for:** Voice of UPSA  
**Prepared by:** Codey Dev — Aka Brown  
**Version:** 1.0  
**Engine:** PostgreSQL (Supabase), schema: video  
**Note:** Nearly identical shape to the podcasts schema — differences are the addition of captions\_url and this feature’s use of public.reports (Section 4)

Table of Contents
=================

1\. Conventions
===============

*   Tables live in a dedicated video schema, referencing the same shared public.profiles table for identity
*   id uuid PK default gen\_random\_uuid(), created\_at/updated\_at on every table
*   Soft delete via deleted\_at on shows and videos

2\. Tables
==========

2.1 shows
---------

| **Column** | **Type** | **Notes** |
| --- | --- | --- |
| id | uuid, PK |  |
| slug | text, unique | Server-generated from title; forms the feed URL path |
| title, description | text |  |
| category | enum: events, interviews, documentaries\_vlogs, sports, academics, other |  |
| thumbnail\_url | text | Cloudinary URL, 16:9 |
| is\_flagship | boolean, default false | Marks "Voice of UPSA TV" for featured placement (Design Brief §1) |
| status | enum: active, inactive |  |
| created\_by | uuid, FK → profiles.id |  |
| deleted\_at | timestamptz, nullable | Soft delete |

2.2 videos
----------

| **Column** | **Type** | **Notes** |
| --- | --- | --- |
| id | uuid, PK |  |
| show\_id | uuid, FK → shows.id |  |
| slug | text, unique per show | Server-generated from title |
| title, description | text | description sanitized before render (TDD T2) |
| video\_url | text | Cloudinary URL (video resource type), location/EXIF stripped at upload |
| thumbnail\_url | text, nullable | Auto-generated by Cloudinary unless Admin overrides |
| duration\_seconds | int | Enforced against the Phase 1 max-duration cap at upload (TDD §6) |
| captions\_url | text, nullable | Optional .vtt file |
| status | enum: draft, published |  |
| published\_at | timestamptz, nullable |  |
| deleted\_at | timestamptz, nullable | Soft delete |

3\. Feed Rendering (not a stored table)
=======================================

GET /video/\[show\_slug\]/feed.xml  
same rendering approach as Podcasts (that schema’s Section 4) —  
SELECT published videos, ORDER BY published\_at DESC,  
render RSS 2.0 with a video enclosure instead of an audio one

4\. Shared Platform Tables (referenced, not owned here)
=======================================================

public.audit\_logs  
Video writes: "show.created", "video.published",  
"video.unpublished", "report.resolved"  
  
public.reports — USED here, unlike Podcasts and the Map  
entity\_type for this feature: "campus\_video"  
reason "no\_consent" carried over from Campus Gallery’s convention  
  
public.notifications — NOT integrated yet (App Flow §3.3)

5\. Row Level Security
======================

| **Table** | **Read** | **Write** |
| --- | --- | --- |
| shows | Public, where status = active; Admin sees all | Admin only |
| videos | Public, where status = published (and parent show active); Admin sees all | Admin only |

6\. Core Relationships
======================

shows 1─└1 videos ─┄1 profiles (created\_by)  
shows, videos ──┄1 public.audit\_logs  
videos ──┄1 public.reports (entity\_type = campus\_video)
