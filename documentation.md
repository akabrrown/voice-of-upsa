User Roles &amp; Permissions</strong></h1><h2><strong>3.1 Role Overview</strong></h2><p>The platform operates on a three-tier role system enforced at both the frontend (UI visibility) and backend (row-level security via Supabase RLS policies). All roles are stored in the Supabase profiles table.</p><h2><strong>3.2 Admin Role</strong></h2><ul><li>Full access to all platform features</li><li>Manage all users: create, edit, suspend, or delete user accounts</li><li>Assign and revoke editor roles</li><li>Publish, edit, unpublish, or delete any article</li><li>Manage advertising: approve, reject, or remove ad submissions</li><li>View analytics dashboard: page views, article performance, ad impressions</li><li>Manage site settings: branding, category configuration, SEO defaults</li><li>Access all audit logs and moderation tools</li></ul><h2><strong>3.3 Editor Role</strong></h2><ul><li>Assigned by Admin via the dashboard</li><li>Create, edit, save as draft, submit for review, and publish articles</li><li>Upload images and media via Cloudinary integration</li><li>Manage own articles: edit or request deletion (admins confirm)</li><li>Access editor dashboard with drafts, published, and rejected articles</li><li>Cannot manage other users, advertising, or site settings</li><li>Can add article categories and tags</li></ul><h2><strong>3.4 Public User — With Account</strong></h2><ul><li>Register and log in via Supabase Auth (email/password or Google OAuth)</li><li>Save/bookmark articles to a personal reading list</li><li>Comment on articles (if comments module is enabled in Phase 2)</li><li>Manage personal profile: name, profile photo, notification preferences</li><li>Subscribe to category-specific email newsletters</li><li>Cannot create, edit, or publish articles</li></ul><h2><strong>3.5 Public User — Without Account (Guest)</strong></h2><ul><li>Read all published articles without restriction</li><li>Browse all categories and search for content</li><li>View advertiser information and submit ad enquiries</li><li>Access About and Contact pages</li><li>Cannot save articles, comment, or access any dashboard</li></ul><h2><strong>3.6 Permissions risk</li><li>Sensitive columns (passwords) never stored directly — handled entirely by Supabase Auth</li><li>Database secrets and service role key never exposed to the client bundle</li><li>Regular
